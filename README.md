# 🎯 Smart Interview System

An AI-powered online mock interview platform built with **Python, Flask & MySQL** for automated evaluation, scoring, reports, and interview history tracking.

## 📌 Overview

Smart Interview System helps students and job seekers practice interviews in a real exam-like environment. It automates the complete interview process — from user registration to evaluation, scoring, and performance reports.

Admin can manage users, questions, and interviews from a centralized dashboard, while users can track their progress over time.

## ✨ Features

### 👤 For Users
- User Registration & Login with Authentication
- Resume Upload & Management
- Attend Mock Interviews (Aptitude / Technical / HR)
- Automated Evaluation & Instant Scoring
- Detailed Performance Report after each interview
- Interview History & Progress Tracking

### 👨‍💼 For Admin
- Admin Dashboard
- Add / Edit / Delete Interview Questions
- Manage Users & Interviews
- View All User Scores & Reports
- Centralized Interview Management

## 🛠️ Tech Stack

- **Language:** Python
- **Framework:** Flask
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Database:** MySQL
- **Tools:** VS Code, Git, GitHub, XAMPP / MySQL Workbench
